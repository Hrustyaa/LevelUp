# Предпросмотр интерфейса LevelUp

Новый Flutter-интерфейс запускается отдельно от штатного MVP.

```sh
flutter pub get
flutter run --target lib/main_ui.dart
flutter test test/ui
```

В предпросмотр входят Splash, онбординг, Home, Focus, Challenge, Progress и Settings. Интерфейс поддерживает английский, русский и казахский языки. На базовой ветке без Android-моста интерфейса выбор установленных приложений и статистика могут быть недоступны. Через «Пропустить» можно перейти к остальным разделам.

Штатный `lib/main.dart` по-прежнему запускает командный MVP. Ветка `feature/core` содержит отдельную реализацию Kotlin и Dart. Предпросмотр читает совместимый статус Focus и сохраняет настройки интерфейса. Для включения Focus из предпросмотра нужен канал `levelup/permissions`. Для выполнения задания дополнительно нужен ответ с `id` и `target` от `consumeChallengeRequest`. Булевый ответ прежнего ядра не открывает задание и не выдаёт доступ. Для списка приложений, экранного времени и уведомлений понадобятся мосты `levelup/app_catalog`, `levelup/usage` и `levelup/focus_notifications` или адаптер к согласованному контракту команды.

В `assets/images/` лежат исходники логотипа и иконки. Генерация launcher icon может изменить Android-ресурсы. В этой ветке добавлены исходные изображения, а существующие Android-ресурсы взяты из командной базы.

Новые UI-коммиты добавляются в существующую ветку:

```sh
git switch feature/ui
git pull --ff-only
git add <изменённые-файлы>
git commit -m "Update LevelUp UI"
git push
```
